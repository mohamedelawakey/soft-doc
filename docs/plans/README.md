# Feature Plans

Use this folder for substantial features that need a detailed execution plan. Keep small tasks in [the current release plan](../plan.md). Start from [TEMPLATE.md](TEMPLATE.md), then name a plan `REQ-###-short-name.md` and link it from its task in `plan.md`.

Update a plan as work progresses. Mark completed work `Done` only after its completion checks pass. Preserve finished plans for traceability; move plans from older releases to [archive/](archive/README.md) and update their links. Files do not archive or delete themselves automatically.
